## ?? FLUJO DE USO RECOMENDADO

### **Workflow 1: Testing de Regresión**

```
1. Ir a tab "Testing" > "Golden Dataset"
2. Dejar version = "v1.0"
3. Click "Ejecutar Golden Dataset"
4. Ver resultados:
   - Pass rate debería ser ~94%
   - Revisar failures
5. Si hay failures:
   - Ver detalle de cada uno
   - Ajustar respuestas o threshold
```

### **Workflow 2: Antes de Publicar v2.0**

```
1. Crear v2.0 (con tus mejoras)
2. Ir a "Testing" > "Comparar Snapshots"
3. Snapshot A: "v1.0"
   Snapshot B: "v2.0"
4. Click "Comparar"
5. Revisar:
   - Recomendación (Deploy / NO deploy / Review)
 - Improvements vs Regressions
   - Cambios detallados
6. Si OK ? Activar v2.0
```

### **Workflow 3: Limpieza de Duplicados**

```
1. Ir a "Testing" > "Detectar Duplicados"
2. Threshold: 0.95
3. Límite: 100 (para empezar)
4. Click "Buscar Duplicados"
5. Revisar pares encontrados:
   - ?? MERGE ? Eliminar duplicado
   - ?? REVIEW ? Revisar manualmente
   - ?? MONITOR ? OK, no acción
6. Eliminar duplicados desde tab "Base Conocimiento" > "Respuestas"
7. Re-ejecutar análisis con más respuestas
```
